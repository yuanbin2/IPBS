# 通用网页剪藏扩展：把当前网页送进我的私有笔记（或博客草稿）

V2.9.1 起本扩展是 **MarkDownload 风格的通用网页剪藏**（自研移植，无第三方运行时依赖），
替代旧的"仅支持力扣题目"入口。在任意网页点击扩展图标 → 选"正文 / 我选中的内容 /
整页预览" → 核对标题、来源与 Markdown 预览 → 默认**保存为我的私有笔记**（仅本人可见），
也可显式改选**博客新文章草稿**（需自己提交审核后才会公开）。

## 权限与边界（实现即约束）

- 权限只有 `activeTab`、`scripting`、`storage`、`offscreen`、`downloads`：没有 `cookies`、`webRequest`、`tabs`、
  `<all_urls>`，没有常驻 content script，没有力扣站点后台监听。`offscreen` 只用于「仅保存图片」时在扩展私有文档里拼接长图，`downloads` 只保存用户请求的截图。
- 只在用户点击"读取并预览"后才读取当前标签页；只取 `document.title`、少量
  `textContent` 候选与正文 DOM，不读 `innerHTML` 之外的整页脚本，不调用力扣任何接口。
- 抽取器不是安全过滤器：来源 HTML/Markdown/URL 都是**不可信输入**，站内
  `imports/html/preview` 会重新校验大小、脚本、属性与 URL 协议。
- 交接正文只放 `chrome.storage.session`（默认不向 content script 暴露），2 MiB 上限、
  64 KiB 分片、SHA-256 校验、5 分钟 TTL、一次性 ack 消费；URL 与历史记录里只有
  随机 nonce、扩展 ID 和 `kind=web`，绝不含正文、网页凭据或博客令牌。
- 扩展不持有博客 access/refresh token；博客页用自身登录态发预览与保存请求。
- 不针对任何特定站点做特权处理：没有站点专用表单，也没有站内"链接建卡"入口，不读取他人题面或题解。
  旧的"力扣题目链接建卡"入口已于 2026-10-07 随 B-041 一并移除，站内也不再提供该导入对话框。

## 本地侧载（Edge / Chrome）

1. `edge://extensions` → 开启"开发人员模式" → "加载解压缩的扩展" → 选择本目录。
2. 若之前装过旧版扩展：在原卡片点"重新加载"，确认版本显示 **0.5.0**，并关闭先前打开的剪藏结果页后重新发送。只刷新博客页面不会更新扩展后台脚本。
3. 若看到“无法打开保存页面/拼接保存失败”：仅保存图片优先用 offscreen 文档拼接，失败时自动改开一个扩展标签页（stitch-page.html），完成后自行关闭；仍失败时保持截图会话 15 分钟，可改选“到博客识别”继续。
4. 生产域名未确定：`externally_connectable.matches` 只登记本地调试 origin。

## 使用步骤

1. 启动博客并登录。
2. 在任意网页点扩展图标 → 选剪藏范围（默认"正文"）→ 点"读取并预览"。
   - 读不到当前标签页或网页限制扩展读取时，弹窗会给出**手动 HTML 导入**入口。
   - 无正文 / 登录页 / 超长时给出具体原因，可换"选区"或"整页预览"重试。
3. 核对标题、来源说明、Markdown 预览与图片警告（远程图片站内确认后才尝试保存；
   懒加载/blob/防盗链图会明确标"需手动上传"）。
4. 选"保存到"：**我的私有笔记**（默认）或**博客新文章草稿** → 点"送到博客"。
5. 博客页自动打开：私有笔记路径先用既有 HTML 安全预览选择区块，再进入"我的笔记"
   抽屉里的**未保存草稿**（含来源链接），点"保存私有笔记"才落库；博客草稿路径走既有 HTML 导入预览与覆盖确认。
6. 私有笔记里的图片经确认后保存为**私有附件**（认证读回，无公开地址）；原站拒绝下载时
   预览保持打开，可重试、改用本地同名图片，或取消该图片区块。

若从旧版本升级且已保存过私有笔记图片，先运行 `python manage.py migrate_private_note_media`
查看数量，再运行 `python manage.py migrate_private_note_media --apply` 将旧文件搬离公开 `media/`。
生产环境要把 `BLOG_PRIVATE_NOTE_MEDIA_ROOT` 配到不被 Web 服务器静态路由暴露的持久目录。

## 截图识别为 Markdown（B-045）

1. 优先尝试上面的正文/选区 HTML 剪藏；页面实际可见却抽不出正文时，在扩展弹窗选择“当前屏”“手动区域”或“长页截图”。普通浏览器设置页等不支持截图。
2. **截图去向**（0.5 起，默认「仅保存图片」）：这是一条与博客完全无关的独立功能——不需要博客地址、不需要博客在运行，也不打开任何博客页面；采集结束后在扩展私有 offscreen 文档里拼成一张长图，直接保存到浏览器下载目录，**不打开博客、不上传任何像素**，随后清理本机暂存。当前屏/手动区域模式同样适用。改选「送到博客识别」时才需要选博客地址。
3. 长页模式（PixPin 式）：点“框选截图区域”，在**要滚动的正文内**拖出完整矩形——上、下、左、右四条边都限定截图范围，请把底部悬浮遮挡物留在框外。松开鼠标就自动截第一屏；等小窗显示第一段，再**在所框正文内自己向下滚动**。扩展会识别整页或内部正文容器滚动，并始终只截固定矩形内随滚动出现的新内容。右下角可拖动小窗逐段显示已截取的拼接预览，滚动停顿时采集，快速滚动会补拍中间屏。第一屏保留框选时的视口并按完整矩形裁剪，不会先跳到别的位置。页面高度只是开始时的估计值，懒加载后可能增长，扩展不会据此判定到底或停下。你确认截够后点小窗的“完成”（Esc 也可），**只有这时**才按所选去向收尾（保存图片或打开博客）；达到上限只会暂停并提示。若框错位置，点“取消”后重新框选。选“送到博客识别”时，博客校对页按真实坐标裁掉选区外内容并拼成一张可下载的长图，同时保留逐屏校对；选“仅保存图片”时不经过博客，长图在扩展内拼接后直接存下载目录。临时原图只存在本机扩展 IndexedDB，成功交接或取消后清理。范围最多 30 个视口、约 30,000 CSS px、20 MiB。若被截断，博客页会显示实际已覆盖范围。

   博客页会**先拼成最终长图，再仅对这张图进行一次本地 OCR**。逐屏图片只用于核对、下载和配图裁剪，不再分别识别；如果拼接失败，会提示重新截取或下载源图，不会把零散视口识别结果当成最终文章。
3. 博客页登录后自动接收截图，或在博客写作页点“截图识别”选择其他截图插件导出的 PNG/JPEG/WebP。OCR 在浏览器本地执行，左边看截图、右边逐块校对 Markdown；默认送入**未保存的私有笔记草稿**，可显式切换为博客草稿。来源截图不会自动上传或公开。
4. 若在校对页主动选择“从源图截取插图”，先选图片用途再上传：私有笔记走私有附件，博客草稿走博客媒体。之后切换保存目标并应用时，校对页会用保留的裁图自动重新上传并替换引用；私有图片转博客媒体前会明确确认，取消则不会公开上传。转换失败会留在校对页供重试。用户仍需自己确认并保存笔记或主动提交博客审核。
5. OCR 模型由 `frontend/scripts/sync-ocr-assets.mjs` 从锁定的 npm 包生成到本站静态目录；`npm run dev`、`npm run build`、`npm run build:check` 会先同步。本地首载需下载约 21 MiB 模型，加上浏览器实际选择的 WASM 运行资源，低配设备可能较慢。运行时不请求第三方 OCR API；模型加载失败会显示错误并允许重试。
6. 如果交接后本地 OCR 失败，保持博客页的识别弹窗打开，可点“重新识别刚才的截图”或逐张“下载源图”；扩展临时副本在成功交接后会清理，关闭弹窗前建议先保存源图。手动区域只提供裁剪，没有涂黑，含个人信息的截图应先自行处理。
7. OCR 文字与配图检测是两条可独立校对的本地链路。扩展截图中的已加载 `<img>` 会携带有界的匿名几何候选；多个 tile 的片段会按坐标、覆盖与可验证重叠信息合并，不依赖 DOM key 单独判定。校对页还会对本地截图/拼接长图运行分段像素规则检测，因此 CSS 背景、canvas 等可能显示低置信度「建议区域」；建议框要由用户确认或调整，规则检测不保证找到所有配图。候选来源、覆盖/部分图片状态会在界面显示。没有候选时仍可从原图手动框选。拼接 JPEG 只用于预览/OCR；最终确认的图片从原始 tile 重组，若采集缺口使完整裁图无法可靠生成会提示用户下载源图或手动处理，不会当成完整图片静默上传。确认裁图后再选私有附件或博客图片上传；上传不等于保存笔记或发布文章。

**限制**：框选完整矩形后请等待第一屏完成，再在框选的正文区域用鼠标滚轮/触控板向下滚动，停顿约半秒让扩展采集；滚得过快时扩展按 85% 框高补拍，期间请保持原标签页在前台。扩展不会在没有新滚动时反复截图；若后台会话失效、页面持续移动或保存失败，小窗会显示错误并可重新开始。每次最多 30 个视口、约 30,000 CSS px、20 MiB、5 分钟。普通内部滚动容器已支持；跨域 iframe 内滚动、虚拟列表反复回收节点、动画或遮挡等仍可能遗漏或错位。小窗只是低分辨率过程预览，最终请对照博客校对页的原图拼接核对。超过画布上限的拼接图会按比例缩小，代码、数字、公式、表格需逐项对照原图。真实网页的工具栏截图采集、20 份人工 OCR 质量样本和 5 位用户任务尚未完成，不能把隔离浏览器合成样本视为这些验收。

**无缩略图/未跳转时**：先到扩展管理页重新加载本项目扩展，再刷新源网页，从浏览器工具栏图标打开扩展并启动长截图（直接把 `popup.html` 当普通网页打开不会授予截图所需的 `activeTab`）。框选后右下角应出现第一屏缩略图；若失败，错误会留在小窗直到点击“关闭提示”，可据此定位原因。必须点击小窗“完成”才会打开博客。

## 常见错误

| 提示 | 处理 |
| --- | --- |
| 读不到当前标签页地址 | 在浏览器另存为 HTML，再到博客写作页手动导入 |
| 剪藏已过期 / 已使用过 | 回原网页重新点扩展发送（5 分钟 TTL，一次性） |
| 正文过长 / 超过 2 MiB | 改用"我选中的内容"缩小范围 |
| 请先登录博客 | 先登录再从扩展重新发送；不在跳转链上携带正文 |
| OCR 显示 `Unexpected token '<'` / 资源清单返回网页 | 旧单端口启动方式会把 `/models/ocr/manifest.json` 错误地返回为博客首页。更新代码后运行 `start.bat` 或 `start.sh` 重新构建并重启，再直接打开该地址确认返回 JSON；`/ort/` 资源也应返回二进制而不是 HTML。若仍使用旧服务进程，需要先停止并重启它。 |
