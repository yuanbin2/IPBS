### B-029 阅读、标注与评论增量（2026-10-01）

当前有编辑权限的用户打开文章即看到可编辑的标题、摘要与可视化正文，单击原位修改；没有权限的读者仅能查看安全 Markdown 预览。编辑器启动时的格式整理不再误报为用户修改。选中文字可以保存仅本人可见的高亮或旁注，也可以提交需要管理员审核的公开评论。审核后，同一工作空间的其他读者在可折叠侧栏看到引用和评论；未审核内容与私人笔记不公开。笔记本改为所见即所得编辑，列表显示格式清爽的摘要。`0038_privatenote_anchor_offset` 和 `0039_blogcomment_quote_anchor` 都只增加可空/有默认值的列，保留历史笔记和评论。本地默认/隔离强安全完整后端各 **193/193**、Edge 全套 **17/17**（含私人/公开选段评论）、前端 `build:check`、Ruff、Black 和迁移一致性检查通过。本地现存 **2 篇已发布文章、1 条私有笔记** 在迁移后仍存在。真实 PostgreSQL、设备和用户验收仍按下述门槛核对，不因此关闭 B-029。

### B-030 阅读排版回归（2026-10-01）

针对本地公开长文“模块 01：Python 与工程基础”复现并修复阅读页代码块错位：预览器生成的安全布局类被 HTML 过滤去掉，容器又保留了 HTML 源码空白，章节还有 8,000px 展开上限。修复后实际 Edge 阅读页的代码栏高度 32px，代码内容、上方表格和章节正常显示；隔离 Edge 的 20 类 Markdown 往返、代码块样式/折叠及脚本过滤专项 **1/1** 和完整浏览器套件 **17/17** 通过，前端 `build:check` 通过。此项无数据库或 API 迁移；原有外部发布验收门槛不变。

### B-031/B-032 阅读导航与编辑宽度（2026-10-01）

公开长文目录原先点击后只高亮、不跳转；标题 ID 被 HTML 过滤剥掉，目录序号与预览器生成的 ID 还相差 1。现仅保留符合 `heading-数字` 的标题 ID，目录按当前预览区标题顺序定位；折叠的父章节自动展开。实际 Edge 长文从目录跳转到“今日学习路线图”后，标题距正文滚动容器顶部约 12px；嵌套标题同样可达。原位编辑去掉 980px 主栏上限、缩小内边距和批注栏，并保留 Vditor 左侧编辑大纲。隔离 Edge 在 1280px 视口确认编辑大纲可见，且大纲与正文合计宽度至少 70%。无数据迁移，其他外部发布验收仍需取得。

### B-033 双击当前位置编辑（2026-10-01）

本人文章默认按 Markdown 阅读排版显示，双击正文时记录目标段落、同文重复序号和双击字符偏移，Vditor 就绪后将光标放回对应文字并把它滚动到可见区域；行内代码产生的零宽字符不会再把定位带回文章开头。编辑时保留文章标题和大纲，折叠非正文元信息，保存走既有待审修订与本机草稿链路。隔离 Edge 长文验证首段和中段行内代码的光标位置、滚动可见性、编辑背景/文字对比、1280px 宽度与提交；全套浏览器 **17/17**、前端 `build:check` 通过。实际作者、移动设备和 Electron 壳仍需可用性验收。

### B-034 单界面直接编辑（2026-10-01）

按最新交互要求，B-033 的双击切换已被替代。有编辑权限的用户打开文章时直接看到可编辑的标题、摘要和 Vditor `wysiwyg` 正文，单击原处输入，不再重建预览 DOM 或显示“编辑/阅读模式”按钮；大纲和正文同屏。无编辑权限的读者只看到经过过滤的 Markdown 预览，没有 `contenteditable`。本机草稿、多标签冲突和明确提交审核保留，提交后作者留在当前界面，公开读者在审批前仍看到旧版。私人高亮与侧边评论保留；正文已有未提交或待审修改时，公开划线评论入口暂停，避免引用尚未公开的文字。隔离 Edge 完整回归 **17/17**，覆盖单击中段、只读权限、标题与正文输入、刷新恢复、评论/笔记及审核；前端 `build:check` 通过。真实桌面壳、移动设备和作者可用性任务仍待验收。

### B-035 编辑工具栏、独立大纲与标题标签（2026-10-01）

原位编辑的插入/格式工具栏现在固定在正文滚动区域顶部，操作条高度由 `ResizeObserver` 实测，避免窄屏换行后相互遮挡。点击或键盘移动光标后，若目标行被固定工具栏盖住，会将其滚回可见区域；普通滚动不会被旧光标拉回。大纲改为正文外侧的独立滚动栏，标题从正在编辑的可视化正文同步，点击后定位到对应段落；编辑器自身内置大纲隐藏。`H1`～`H6` 层级伪标签默认隐藏，作者可用“显示标题层级”开关查看。窄屏时大纲置于正文上方并独立滚动。隔离 Edge 的 20 类 Markdown 长文专项验证滚动后工具栏仍贴顶、目录不随正文滚动、可独立滚动并跳到表格章节、`H3` 开关、390px 布局、光标可见及提交审核；前端 `build:check` 通过。实际移动设备和 Electron 壳的使用手感仍需按 B-025/B-034 验收。

本轮完整浏览器回归第一次为 **16/17**：长文编辑项通过，评论审核项的一次登录请求超过 8 秒测试等待；单独重跑该评论项 **1/1** 通过。该偶发登录超时仍应在远端 CI 首跑时观察，不能把分开通过写成同一次完整 **17/17**。

### B-036 只读文章大纲响应式修复（2026-10-02）

先前的 `max-width: 1300px` 规则把只读文章大纲隐藏，导致常见笔记本宽度的普通读者没有目录。现在有标题时，读者与作者共用正文外侧的大纲布局：桌面侧栏独立滚动，390px 窄屏置于正文上方。隔离 Edge 的只读长文专项在 1280px 与 390px 确认大纲可见，并在 1280px 点击“09 表格”跳到对应标题；同一测试还覆盖无编辑权限、嵌套标题、编辑态与保存。前端 `build:check` 通过。无数据库迁移。

### B-037 评论提交后直接公开（2026-10-02）

按最新产品规则，已登录且未被限制的读者，对当前 workspace 内已发布、可阅读的文章提交普通评论或选段评论后立即公开。评论接口返回 `approved`，文章评论数和侧边讨论通过详情刷新即时更新；管理员不再需要审批新评论，因此也不产生新待审提醒。“评论管理”默认展示已公开内容，可隐藏违规评论、处理举报和旧版本遗留的待审记录。匿名提交仍为 403，草稿/其他 workspace 的提交为 404，每账号限流和缓存故障保护不变。博客后端类 **38/38**（其中评论权限专项 **5/5**）、隔离 Edge 普通/划线评论及举报隐藏 **2/2**、前端 `build:check` 通过；无迁移。真实共享 Redis、运营响应与真库验收仍归 B-021。

### B-038 大量评论时的加载与查找（本地实现，外部待验收）

新前端详情使用 `include_comments=0`，侧栏展开与文末进入视口后分别按需读取，每批最多 20 条；旧无参数评论接口兼容。1,000 条混合评论的本地分页测试、博客后端类 **39/39**、前端 `build:check`、迁移一致性，以及隔离 Edge 匿名阅读/模拟 120 条翻页/真实新评论与举报隐藏专项通过。**真实 PostgreSQL 1,000/10,000 条查询计划、接口 P95 与 5 名读者找评论任务未执行**，不能关闭 B-038。详见 [评论侧栏扩展设计 V2.2](评论侧栏扩展设计V2.2.md)。

### B-039 Agent 能力与安全一致性（本地修复，模型质量待验收）

SQL Agent 聚合现按 JWT 工作空间隔离；Review Agent 利用已保存的上一条回答和来源给出结构化证据缺口，明确不自动判定事实；联网与 RAG/MCP Supervisor 的 REST/SSE 结果统一脱敏，公开博客 Agent 返回、持久化及历史读取同样脱敏，模型异常轨迹不再展示异常原文。本地默认/强安全后端各 **199/199**，隔离 Edge 原套件 **18/18** 与新增 Agent 专项 **1/1**，前端构建通过。**尚无真实模型事实质量、真 PostgreSQL、真 Nginx 与远端 CI 证据**；详见 [Agent 能力增强与验证记录 V2.3](Agent能力增强与验证记录V2.3.md)。

## 代码与仓库风险

- B-020：`app-desktop/.edge-profile/` 仍有 **1,468 个 Git 已跟踪文件**；`.gitignore` 无法取消既有跟踪。本轮按工作区保护要求只读核查，未改该目录或索引。公开仓库发布前需独立审计和备份，再处理跟踪与可能的历史敏感内容。
- B-021 改为登录后评论，旧匿名评论客户端会收到 403；这属于有意的接口行为变化。B-011 旧 JSON refresh 端点仍存在，不能宣称令牌过渡已经完成。
- B-021/B-037 新评论直接公开，管理员仍可隐藏违规内容并处理举报和历史待审评论。举报记录由 `0034_comment_reports` 存储，账号限制及申诉由 `0037_blog_interaction_restrictions` 存储。部署必须按迁移链 `0033`→`0034`→`0035`→`0036`→`0037` 升级；旧已批准评论由 `0033` 回填为已审核。回退到先审后发代码会改变新评论行为，应先告知用户并核对历史待审评论、未处理举报及有效限制。真实共享 Redis、真库并发与举报/申诉响应时间仍是发布阻断。
- B-025A `0035_article_revisions` 使已发布文章的修改先进入待审修订，公开链接在审批前保留旧版。旧前端 `PUT` 若缺 `publication_version` 会收到 409；应先部署兼容新字段的前端，再开放新版编辑。B-025B 阅读页原位可视化编辑已在隔离 Edge 本地通过，移动端、实际 Electron 和作者可用性任务仍待验证。
- B-027 `0036_privatenote` 建立私有笔记表；旧“我的笔记”投稿入口在新界面更名“我的文章”。私有笔记 API 必须由真实 JWT 用户访问，笔记不进入公开 RAG。部署前应备份；回退旧代码不应删除笔记表，撤销迁移会永久丢失笔记。实际移动端/桌面壳体验、真库迁移和用户任务仍待验证。
- B-028 无数据库迁移，复用现有写作助手配置；只有用户点击汇总时才发送本人所选笔记到模型。服务端限制最多 10 条、正文总长及每小时调用次数，错误不回显私有正文。模型输出只作为可编辑建议，必须核对来源，不能据 mock 浏览器响应宣称摘要质量。真实共享 Redis 多实例、服务商数据处理条件、成本与人工质量验收仍是发布阻断。回退可隐藏汇总入口并禁止 `note_summary`，已有私人笔记不受影响。

- 默认公开博客只读取 `default` workspace 的已发布文章。其他 workspace 若需公开展示，必须设计显式站点地址与授权映射；不能去掉后端 workspace 过滤。
