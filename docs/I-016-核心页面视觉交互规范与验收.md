# I-016 核心页面视觉与交互规范

2026-10-24，本轮以现有 `frontend/src/style.css` 的深绿、浅灰和暖金变量为基线，检查领域目录、知识库和对话三条主路径；保留 Element Plus 按钮、输入框和弹窗组件。博客阅读与写作沿用现有全局变量和 I-015 的流程，本轮未逐页改造。

## 共用规则

| 项目 | 规则与本轮落点 |
| --- | --- |
| 字体和层级 | 正文使用 `--font-family` 与 `--font-size-base`；辅助文案用 `--font-size-sm` 和次级文字色；代码沿用 `--font-mono`。长标题允许换行。 |
| 间距和表面 | 优先使用 `--space-*`、`--radius-*`、`--color-bg-surface`、`--color-border`；领域卡片移除本地硬编码色和间距。 |
| 按钮、表单、弹窗 | 保留 Element Plus 的主次按钮、禁用和加载反馈；领域目录搜索可回车提交；知识库新建弹窗在窄屏采用视口内宽度。危险操作仍走原有确认弹窗。 |
| 状态反馈 | `PageFeedback` 统一加载、空、错误、部分成功的标题、下一步与可选动作。失败时保留已有资料；重试仍调用原请求。 |
| 焦点和溢出 | 会话历史用真实按钮选择，焦点可见；Markdown 长代码、宽表格在内容容器内横向滚动，超宽图片缩放到容器内。窄屏对话调整外边距与侧栏最大高度。 |

## 状态与后端语义

- 领域目录：加载、空数据、无搜索结果、请求失败分别显示原因和刷新、清除搜索或重试入口。错误时不把旧列表伪装成“空数据”。
- 知识库：知识库/文档列表请求检查 HTTP 状态；其中一路失败而另一路已有数据时显示“部分资料暂时无法更新”；检索失败可重试，上次检索结果仍保留并明确标为上次结果。上传与重新处理继续使用原异步任务状态。
- 对话：会话列表、分页和历史内容请求失败时保留当前可用内容并提供重试。会话选择是可用 Tab、Enter 操作的按钮。后端 SSE `progress`/`trace` 只映射已知阶段为用户提示，未知内容显示“处理请求”，不会把查询改写、私有文本或内部路由原文呈现；完成的历史步骤使用过去时。运行失败、超时、取消提供对应下一步；断线时仍说明“停止接收”不等于取消后端执行。正文增量仍由原 SSE 事件驱动，未用动画假装模型流式。
