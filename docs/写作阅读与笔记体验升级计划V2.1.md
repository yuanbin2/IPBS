## 当前问题与目标

阅读页已可在正文位置切换为 `Vditor` 的 `wysiwyg` 编辑器，旧独立写作入口仍供新建文章使用。此前 `BlogArticleDetailView.put` 修改已发布文章会让公开链接消失，B-025A 已改为待审修订，待真实 PostgreSQL 升迁验收。博客列表已有分页、组合筛选与 URL 状态保留，仍缺真库性能和非作者找文任务证据。原“我的笔记”已更名“我的文章”，独立私有笔记可在阅读页旁记录与检索；真实用户任务仍待完成。

笔记侧边栏现可手动勾选最多 10 条笔记，并在点击“汇总已选笔记”时调用现有写作助手。服务端只读取当前登录者同一工作空间的笔记，汇总后显示实际纳入来源、截断和模型信息；生成内容可直接可视化修改，亦可复制或另存为私有笔记。每账号每小时最多 10 次模型调用，真实共享 Redis 和模型成本/质量仍待验收。

目标是作者在自己的文章中按“编辑”即可在当前阅读位置改写格式化正文，读者在审核期间继续看到上一个已发布版本；通过可检索列表快速找到文章；阅读时能留下私有笔记，并由现有写作助手 API 按需汇总笔记。所有 AI 输出先给用户审阅，不自动改写文章或发布。

## 关键交互与边界

- **编辑权**：普通作者只能改自己的文章；管理员可处理审核。前端按钮只是提示，API 必须独立校验角色、作者和 workspace。已发布文章在审批前保持公开快照；访客绝不能看到待审修订。
- **自动保存**：本机缓存仍按账号、workspace、文章 ID 隔离；服务器保存要有版本令牌，两个标签页冲突时暂停覆盖并让用户选择。切换阅读与编辑不能重建空编辑器覆盖未保存内容。
- **笔记隐私**：私有笔记不经公开博客接口、公开搜索、推荐或博客助手返回。仅在用户点击汇总时将所选笔记发给现有写作模型；界面展示来源和截断，服务端不接受客户端代传正文。模型错误时保留原笔记且提供重试。模型服务商会接收所选内容，正式使用前须确认其数据处理条件与成本。
- **指标**：记录保存失败率、冲突率、编辑任务完成时间、找文章成功率、搜索零结果率；只记录聚合指标，不把私有笔记正文写入分析日志。指标先建立基线，再定正式门槛。
