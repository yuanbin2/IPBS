# 模板填写样例：I-017 公开文章直达页

日期：2026-10-24。此样例把[新功能设计模板](templates/新功能设计模板.md)用于已实施的 I-017；具体证据与方案比较见[I-017 决策记录](I-017-公开文章SEO与分享决策.md)。它不是一次新的生产验收。

## 基本信息与用户场景

- **状态**：本地验证通过，部署和真实抓取待验；I-017 不关单。
- **场景**：读者直接打开或分享 `/blog/<slug>/`，希望 HTML 首包包含该公开文章的标题、摘要和分享信息；作者修改或撤回后，下一次直达请求应反映当前状态。
- **原问题**：原直达 HTML 是通用标题加空 `#app`，没有文章专用描述或首包文字。范围只包括默认 workspace 的已发布单篇文章；不迁移全站 SSR，不预渲染私有正文。

## 流程与状态

| 步骤 | 入口/执行者 | 前置状态 → 后置状态 | 用户看到什么 |
| --- | --- | --- | --- |
| 直达 | Django `public_article_page` | 已发布文章，读取不改变发布状态 | HTML 标题、摘要、canonical、OG/Twitter；Vue 接管正文 |
| 站内跳转 | Vue Blog 页 | 路由变化，数据库状态不变 | 浏览器标题与分享元信息同步 |
| 修改/撤回 | 文章修订审批或操作者状态入口 | 待审修订保持旧公开版；批准后新公开版；归档后非公开 | 直达下次请求读取现行版；归档 URL 返回 404/noindex |

这里没有新增持久任务或缓存失效任务；发布状态仍由 `BlogArticle`/`BlogArticleRevision`/`ApprovalRequest` 管理。

## 数据模型与文件

| 对象/字段/索引或存储 | 创建、读取、更新、删除时机 | workspace/owner 与保留规则 | 迁移/兼容影响 |
| --- | --- | --- | --- |
| `BlogArticle.status/summary/title/slug/published_at` | 请求时只读当前发布行 | 仅默认 workspace 且 `published` 可进入公开 HTML | 无新迁移 |
| Vite `dist/index.html` | 后端构建时复制同版本入口，请求时注入安全元信息 | 构建物不含数据库文章 | 前后端镜像必须同版本发布/回退 |
| `/robots.txt`、`/sitemap.xml` | Django 按当前公开行响应 | 不列草稿、撤回或其他 workspace | 路由与 Nginx 精确代理需同步 |

## 权限与信任边界

| 动作 | 谁能做 | 服务端在哪一层核验 | 跨用户/跨 workspace/伪造 ID 怎么处理 |
| --- | --- | --- | --- |
| 读取公开直达页 | 匿名读者 | `backend/config/public_article_page.py` 按默认 workspace + published 查询 | 不存在、未发布、跨 workspace 均返回 404/noindex 壳 |
| 修改/归档文章 | 作者可提交修订；归档由操作者发起 | `views/blog_articles.py` 的所有权、角色、版本与审批判断 | 伪造 slug/版本不得绕过 workspace 或审批 |

数据库正文及页面摘要是非信任内容，输出经过转义/安全提取；待审修订不进入公开 HTML。前端路由仅负责显示，公开性由服务端判断。

## API / 事件契约

| 方法与路径/事件 | 关键输入 | 成功状态与响应 | 冲突、失败、重试或幂等规则 |
| --- | --- | --- | --- |
| `GET /blog/<slug>/` | 单段 slug | 200 HTML，公开元信息、摘要及 Vue 入口，`no-store` | 私有/撤回/跨空间为 404 + `X-Robots-Tag: noindex, nofollow` |
| `GET /api/agent/blog/articles/<slug>/` | slug | Vue 正文按原 API 获取 | 原有权限与 404 行为不变 |
| `GET /sitemap.xml` | 无 | 当前公开文章 URL | 不列非公开内容；无独立构建缓存 |

## 异常与恢复

- 文章状态变化按请求读取数据库；代理或第三方分享平台缓存若忽略 `no-store`，需要运维核查，应用无法保证第三方旧卡片立即清除。
- 前后端镜像版本不一致可能引用错误资源哈希；回退应同时恢复两镜像及文章代理规则。该改动无数据库迁移，不需要回滚用户文章。
- 错误输出不包含私有正文。此流程无新任务 ID；部署排障使用应用/代理请求日志，避免记录私有文章正文。
