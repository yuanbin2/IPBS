**结论：初步诊断完成，不能据此确认当前复杂方案有实际收益；B-056 暂不关闭，也不修改生产权重。**本轮使用 28 条完全合成、无私人资料的固定切片和 38 条 Codex 起草的来源映射题（调参 24、独立验证 14）。标注状态为 `assistant_draft_unreviewed`，没有人工 reviewer；以下命中率只用于检查评测管线与暴露失败，不是经人工确认的真实答案质量。

## 方法与复现

从仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe backend\scripts\evaluate_rag_i001.py --embedding local_hash --output docs\evaluation\i001-local-hash-v1.json
```

输入为 [语料快照](../backend/apps/agent_api/eval_data/i001_corpus_v1.json)和[问题与暂定来源映射](../backend/apps/agent_api/eval_data/i001_questions_v1.json)，原始逐题排名、耗时和 SHA-256 在[机器结果](evaluation/i001-local-hash-v1.json)中。语料 28 个 chunk、15 个文档；题型包括中文人名、指代追问、版本与重复材料、无答案。验证集在生成前单独固定，未用于改权重；但它同样未经人工审核，不能称盲测金标准。

使用现有 `keyword_similarity`、384 维 `local_embedding`、`hybrid_relevance_score`、`rerank_search_results`、`diversify_search_results`。所有分支共享语料、Top-K、双语查询扩展和文档多样性；向量为全量 exact 对照。五个主分支依次只添加一个因素：关键词；向量；0.72/0.28 混合；混合加现有**无 LLM 时的确定性历史拼接**；再加当前 0.4 规则重排。另只将重排系数改为 0.2/0.6 作敏感性诊断。这里没有运行生产数据库、pgvector、LLM 改写或回答生成。

Recall@5 分母仅为有暂定来源的题，MRR@10 为首个暂定来源的倒数排名均值。无答案题单列“返回任意候选”，不把候选出现视为回答编造。P50/P95 是单次本机逐题排序加一次缓存测得的查询 embedding 耗时；不是 HTTP、数据库或端到端延迟，且 14 题样本的 P95 很不稳定。索引建向量耗时为 4.568 ms，未计入每请求。数据版本 `i001-synthetic-v1` / `i001-questions-v1`；嵌入 `local-hash-embedding`、`sha256-token-hash-v1`；查询改写为当前代码的 deterministic fallback。代码、提示词和数据文件哈希详见机器结果 provenance。生成模型、生成提示词、价格版本均为 `not_run`。

## 失败案例与未测指标

- `q25`“它的 P95”：纯向量未在前五命中星河性能切片 `c08`，拼接历史后命中；这是历史消解收益的暂定线索。
- `q28`“那日志能保留多少”：混合仍漏掉兰亭留存切片 `c21`，拼接历史后命中。
- `q29`“它用什么指标评测”：混合、历史拼接及三个重排系数均未将 `c26` 放入前五。双语扩展还把“方案设计”误提为姓名，生成了无关拼音别名，需单列失败复核。
- `q36`问 2027 年活跃用户，语料仅有 2025/2026 年数字，各分支仍返回近似指标切片；是否诚实拒答未运行生成模型，不能由候选列表判定。

**答案依据性：未测（无人工复核的回答主张）；完整请求成本：未知（没有执行回答模型，也没有 I-005 AgentRun）。**脚本可通过 `--answer-records` 读入逐题 I-005 `model_accounting` 导出与人工审核记录；只有所有题目的模型 API 成本都可计价且价格版本/币种一致时才给本地哈希路径的 API 成本合计，只有 `human_reviewed` 且有 reviewer 的回答才进入依据性汇总。远程 embedding 无用量回传时仍为未知；基础设施成本不含在 I-005 价格表内。未经复核的自动答案保持 `null`，不能作为真值。检索阶段本地哈希无外部 API 费用，但 CPU、数据库与完整回答费用并非零。

真实 embedding 独立尝试：使用已配置的 `text-embedding-v1` API 别名，仅对合成语料发起一次远程索引请求；返回 `EmbeddingRequestError: embedding_request_failed:APIConnectionError`，没有生成有效远程向量或排名，**真实 embedding Recall/MRR、延迟和费用均未测得**。临时评测标签 `text-embedding-v1-api-alias-unpinned` 不是服务商修订版本；正式比较前需确认模型版本、网络、价格配置与用量回传。不把失败的请求算作远程评测通过，也不与本地哈希结果混算。

远程复跑需在有网络及测试凭据的隔离环境显式设置 `RAG_EMBEDDING_MODEL_VERSION`，再执行同一脚本的 `--embedding remote --allow-remote --output docs/evaluation/i001-remote-v1.json`；脚本不打印密钥，远程失败时不会生成成功结果文件。
