# 智能体答案质量与人工复核计划 V2.4

> 2026-10-02 记录，**待实施**。这是后续工作方案，不代表已有人工标注或真实模型质量通过。关联 B-008、B-009、B-028、B-039；当前发布门槛仍以[评测与测试升级方案 V2.0](评测与测试升级方案V2.0.md)为准。

## 当前证据与目标

- 后端默认/强安全各 199/199、本地浏览器专项通过，证明路由、权限、输出协议与故障回退可运行；模型 API Key 在测试中清空，不能据此推断答案事实质量。
- 内置评测题 30 条，人工审核 0 条；缺至少 40 条双人标注的冻结核心集、评分器与人工的一致性校准。`evidence-rubric-1.2` 对未审核/不可判定项返回 `needs_review`，不能把“有引用”当成“引用支持结论”。
- Review Agent 只检查最近回答与已保存来源的结构关系，无法替代领域专家判断语义真实性。私有笔记汇总 B-028 另缺真实模型与 20 份摘要的人工事实审阅。

目标是用可复现的人工真值、分场景质量门槛和线上失败回流降低错答风险；不存在“100% 保证正确”的模型承诺。

## 人工如何介入

| 阶段 | 人工职责 | 系统职责与留痕 |
| --- | --- | --- |
| 标准集 | 两名标注者独立审核问题、期望路由、可回答性、原子事实、允许来源 ID、禁止主张和拒答条件；分歧由第三人裁决。 | 题目与语料、来源 revision、标注 schema、标注人和时间保存为版本化冻结快照及 hash；草稿标签不能伪装人工真值。 |
| 上线前 | 复核自动评分 `needs_review`、错误引用、冲突材料和高风险任务；签署发布决策。 | 在相同数据集、语料、模型、提示词与评分器版本下比较新旧结果，展示分子/分母、切片及失败样本；隐私越权、伪造引用直接阻断。 |
| 使用中 | 用户标记事实错误、来源不支持、答非所问或过时；审核员抽查并裁决，不把点赞当真值。 | 记录脱敏回答、来源、工具路径、版本和反馈理由，避免保存密钥/私人全文；低置信、缺来源、差评及高风险结果进入复核队列。 |
| 修复后 | 负责人按检索、索引、路由、工具、提示词、模型、语料过时、权限等原因归类；新失败经人工审定后进新版本题库。 | 一次修改一个主要环节，跑冻结回归与安全门禁；记录回滚与线上监测，不用同一组题无限调参再报“通过”。 |

## 先做的最小批次

1. 从真实但去标识化的用户问题与公开文章中选 40 题，覆盖 RAG、公开博客、SQL、联网、写作、审查、拒答、跨 workspace、工具故障、材料冲突及提示注入；先双人标注和分歧裁决，再冻结。扩展到方案中的 160 题时，至少 20% 第二人复核，重点危险切片仍全部双审。
2. 用人工集审查 `evidence-rubric-1.2` 的误判：尤其同句多事实、来源只支持部分结论、文档过时、正确拒答和无需行内引用但仍需可见证据的情况。需要语义判断的结果由人裁决，规则/模型裁判只用于筛查。
3. 有测试密钥、成本上限及用户授权后，运行一次真实模型隔离批次；分别报告检索 Recall@5、答案正确性、忠实度、引用准确率/覆盖率、拒答质量、工具成功率、P95 延迟与实际费用。现有首版目标依次为 Recall@5 ≥0.90、正确性 ≥0.90、忠实度 ≥0.90、引用准确率 ≥0.95、覆盖率 ≥0.90、拒答质量 ≥0.95；同时给出样本数和 95% 置信区间，不拿小样本百分比概括全体用户。
4. 为 B-028 固定 20 组有冲突、噪声、长短变化的私有笔记，两人逐事实审阅支持关系、遗漏、误引和泄漏；未经明确授权不批量调用付费模型。
5. 再做用户反馈入口、人工审核队列与抽样策略。上线后随机抽样与“无来源/拒答异常/用户差评/高风险”定向抽样分开统计，避免只看失败反馈造成总体质量估计偏差。

## 发布与运营边界

- 公开回答默认显示可点击来源；无证据时诚实说明不确定。Review Agent 的“引用存在”结论不得标记为“事实已核实”。
- 跨 workspace 泄漏、私人笔记外泄、未授权工具动作、编造引用均为阻断项；正确性等比例门槛不能抵消这些问题。
- 人工复核涉及私人笔记时，只让有授权的本人/指定审核角色在最小权限范围内查看，日志仅存去标识化证据。对外部模型的数据处理与费用先确认。
- 状态保持**待实施**；完成标注、真实模型评测和运营试点后，回填实际数据、审核人、版本、成本及失败案例，才能决定关闭 B-008/B-028 的质量部分。
